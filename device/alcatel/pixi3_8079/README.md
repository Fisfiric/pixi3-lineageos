Device tree for the Alcatel OneTouch Pixi 3 (10) WiFi, model 8079 (TCL, MediaTek MT8127)
=======================================================================================

Based on mt8127/android_device_alcatel_ttab (cm-14.1, Telekom Puls). Panel, touch and
charger support lives in the kernel tree (kernel/alcatel/pixi3_8079, pixi3_8079_defconfig).

Spec     | Pixi 3 (10)
--------:|:------------
SoC      | MediaTek MT8127, quad Cortex-A7, Mali-450
RAM      | 1 GB
Display  | 10.1", 800x1280 (Raydium RM68200, TXD module)
Storage  | 8 GB eMMC
Touch    | Goodix GT9xx
Charger  | BQ24158
Android  | 5.0.1 stock (vE6I-0), LineageOS 14.1 (7.1.2)
